# Snaps – User Guide

## Quick start
1. Click the **Snaps** icon in the Chrome toolbar (pin it via the puzzle-piece menu for one-click access).
2. Choose **Select area**, **Visible part** or **Full page**.
3. Annotate if you like, then **Copy** or **Download**.

## Capture modes
| Mode | How | Shortcut |
|---|---|---|
| Select area | Drag a region on the page. Move or resize it with the handles. A magnifier shows exact pixels; press **C** (before you start dragging) to copy the colour under the cursor. | Alt+Shift+A |
| Visible part | Captures what is on screen right now and opens the editor | Alt+Shift+V |
| Full page | Auto-scrolls and stitches the whole page. Sticky headers show once. Up to 16,000 px tall. | Alt+Shift+F |

You can also right-click any page → **Snaps: Capture …**.
Use the **Timer** (3 / 5 / 10 s) to capture menus and hover states.
Change shortcuts at `chrome://extensions/shortcuts`.

## Annotation tools
Select/move · Pen · Highlighter · Line · Arrow · Rectangle · Ellipse · Text · Numbered step · Emoji stamp · Blur · Pixelate · Undo/Redo.
Pick colour and stroke size in the Style panel. In the editor you can also **crop, rotate and flip**.

**Hide sensitive info:** use **Blur** or **Pixelate** on emails, names, tokens and account numbers before sharing.

## Beautify
Switch on **Beautify** in the editor to add a backdrop colour, padding, rounded corners, a shadow and an optional window frame (light/dark).

## Saving and sharing
- **Copy** – image to clipboard, ready to paste into chat, email or docs.
- **Download** – PNG, JPG, WebP or PDF. Files are saved in `Downloads/Snaps/`.
- **After capture** (popup → settings): open the editor, copy immediately, or download immediately.

## Gallery
Click the gallery icon (or **View all**) to browse recent captures. Filter by type, re-edit, copy, download or delete. All data stays in your browser.

## Settings
Theme colour (6 options), light/dark (follows your system), default format, after-capture action and timer.

## Troubleshooting
| Problem | Fix |
|---|---|
| "Chrome doesn't allow captures on this page" | Chrome blocks extensions on `chrome://` pages, the Chrome Web Store, and the built-in PDF viewer/new-tab page. Use a normal website tab. |
| Shortcut does nothing | Another extension may own it. Reassign at `chrome://extensions/shortcuts`. |
| Local files (`file://`) | Turn on **Allow access to file URLs** for Snaps in `chrome://extensions`. |
| Full-page capture looks cut off | Some sites scroll inside a container; Snaps detects most of them. Try again after the page has fully loaded. |
| Copy fails | Make sure the tab is focused and Chrome has not blocked clipboard access for the extension. |

## Privacy
No account, no uploads, no tracking. See the privacy policy.
